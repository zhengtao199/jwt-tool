# JWT 解码 / 编码 / 密钥字典工具

本地运行的 Web 应用（Node.js 后端 + 原生前端），**零第三方依赖**，所有计算在本机完成，不发起任何外部网络请求。

## 启动

**方式一（推荐）：双击 `start.bat`** — 自动定位 node、启动服务并打开浏览器；关闭那个黑窗口即停止服务。

**方式二：命令行**

```bash
cd jwt-tool
node server.js          # 或 npm start
```

默认监听 `http://127.0.0.1:5273`；端口被占用会自动顺延到 5274、5275…（控制台会打印实际地址）。
可用 `PORT=8080 node server.js` 指定端口；设置 `JWT_NO_OPEN=1` 可关闭「启动后自动打开浏览器」。

## 打不开怎么办

1. 页面顶部出现红色横幅「无法连接后端服务」→ 说明服务没在运行，双击 `start.bat` 后点「重试」或刷新页面。
2. 提示端口占用 → 服务会自动换端口，看控制台打印的实际地址；也可 `PORT=9000 node server.js`。
3. `start.bat` 报「未找到 node.exe」→ 先安装 Node.js 16+，或把 node.exe 所在目录加入 PATH。

## 功能

| 模块 | 说明 |
| --- | --- |
| 解码解析 | 粘贴 JWT 自动解析；三段原文着色展示、header/payload 语法高亮、`iss/sub/aud/exp/nbf/iat/jti` 时间字段可读化与过期倒计时；`alg=none`、空签名、缺少 `exp` 等风险提示 |
| 密钥字典 | 增删改查密钥（支持 UTF-8 / Base64 / Hex 三种编码），一键用全部密钥重算签名做校验，命中即显示命中的密钥与算法；首次启动预置 5 个常见弱密钥 |
| txt 导入 | 选择 `.txt` 文件批量导入（也可直接粘贴）：一行一个密钥，支持 `备注:密钥` / `备注,密钥` / `备注\t密钥`，`#` 开头为注释，整批指定编码并按内容去重，导入后回显新增/跳过/总数。默认上限 **64MB / 200 万行**，超大文件走裸流上传（不载入预览框） |
| 字典管理 | 列表按 100/500/1000 条分页渲染 + 备注/密钥内容搜索，百万级字典也不卡页面 |
| 签名校验 | 解码页可勾选「解码后自动校验」（开关存 localStorage，粘贴即出结果）；字典列表可勾选密钥，校验只跑选中项（大字典下更快）。字典超过 20 万条且未勾选时，自动校验会跳过并提示手动触发 |
| 编码签发 | 选择 HS256/384/512，用字典密钥或手动密钥签发新令牌，可自由编辑 header/payload JSON，一键追加 24 小时过期时间 |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/decode` | `{token}` → 解析结果与风险提示 |
| GET/POST/PUT/DELETE | `/api/keys` | 密钥字典查询 / 新增 / 修改 / 删除 |
| POST | `/api/keys/import` | `{content, encoding, dedupe}` → 按行批量导入，返回 `{keys, imported, skipped, problems}` |
| POST | `/api/verify` | `{token, ids?}` → 用字典逐条校验签名，返回命中项 |
| POST | `/api/sign` | `{header, payload, secret|keyId, alg, encoding}` → 新令牌 |

## 数据与文件

- `data/keys.json`：密钥字典持久化位置，删除即恢复默认弱密钥字典。
- `public/`：前端页面（`index.html` / `styles.css` / `app.js`）。

## 大字典说明

| 项目 | 默认 | 调整方式 |
| --- | --- | --- |
| 单文件上限 | 64 MB | `JWT_MAX_UPLOAD_MB=200` |
| 单次最多解析行数 | 200 万 | `JWT_MAX_LINES=5000000` |
| 字典总条数上限 | 500 万 | `JWT_MAX_KEYS=5000000` |

实测：100 万条（17MB）导入约 4 秒；用 100 万条字典校验一个令牌约 9 秒（校验分批让出事件循环，期间服务仍可响应）。字典越大，`data/keys.json` 越大、启动读取越慢，属正常现象。

## 已知限制

- 签名校验与签发只支持 HMAC 系列（HS256 / HS384 / HS512）；RS/PS/ES 等非对称算法仅做解码与提示，需另行提供 PEM 公私钥。
- 仅监听 127.0.0.1，不对外暴露；如需局域网访问请自行评估风险后再改 `HOST`。
